# Trapping Rain Water                                                                                                                                                                                                                       
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
## Problem Description                                                                                                                                                                                                                      
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
Given an array of non-negative integers representing an elevation map where each value represents the height of a bar with width 1, compute how much water it is able to trap after raining.                                                
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
## Examples                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Example 1:**                                                                                                                                                                                                                              
                                                                                                                                                                                                                                            

Input: height = [0,2,0,3,1,0,1,3,2,1]                                                                                                                                                                                                       

Output: 9                                                                                                                                                                                                                                   

                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Example 2:**                                                                                                                                                                                                                              
                                                                                                                                                                                                                                            

Input: height = [4,2,0,3,2,5]                                                                                                                                                                                                               

Output: 9                                                                                                                                                                                                                                   

                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
## Constraints                                                                                                                                                                                                                              
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
*   `1 <= height.length <= 1000`                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
*   `0 <= height[i] <= 1000`                                                                                                                                                                                                                
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
## Recommended Time & Space Complexity                                                                                                                                                                                                      
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
You should aim for a solution with `O(n)` time and `O(1)` space, where `n` is the size of the input array.                                                                                                                                  
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
## Hints                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Hint 1:** A brute force solution would be to check every pair of bars and calculate the water they can trap. This would be an `O(n^2)` solution. Can you think of a better way?                                                           
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Hint 2:** Try using the two-pointer approach. We start with the widest possible container (pointers at the ends of the array) and try to find a better one by moving the pointers.                                                        
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Hint 3:** Which pointer should we move? If we move the pointer pointing to the taller bar, can we potentially get a larger area? If we move the pointer pointing to the shorter bar, what happens?                                        
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
**Hint 4:** The amount of water is limited by the shorter bar. By moving the shorter bar's pointer inwards, we might find a taller bar that compensates for the reduced width, potentially increasing the area.
